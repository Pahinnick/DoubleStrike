# Booster recipes

`boosterRecipes.json` describes how each draftable set's real booster packs were collated, at
rarity level: the slots, pack variants (for example "1 in 3 packs has a foil in place of a common"),
the rare-to-mythic ratio, wildcard and foil rarity splits, land slots, and bonus sheets. Draft mode
opens packs from it (see `../boosters.ts`).

It is generated by `scripts/convert-boosters.mjs` from the booster definitions in
[taw/magic-search-engine](https://github.com/taw/magic-search-engine) (`data/boosters/`, the data
behind [mtg.wtf](https://mtg.wtf/)'s pack simulator). Those definitions are compiled from Wizards of
the Coast's "Collecting …" articles, The Collation Project and 17lands pack-opening data. Generated
from commit `182f7da39abb785480472e695c0a8808911c756e` (November 2026).

Card names, rarities and other card data are looked up from Scryfall at runtime; this file holds
only collation structure and rates.
